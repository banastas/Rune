01

Nothing lost between Macs

The scratch file lives in Rune's own folder in iCloud Drive; any other file stays where it is. Rune saves as you type, uploads each version itself, and says in the strip how far each version has got. Every difference between Macs is merged or shown: no text any Mac wrote is dropped without you seeing it.

In the journal first

Every edit goes into a recovery journal on this Mac within 300 ms, written through to the disk before it counts. A crash, a force quit or a kernel panic loses at most the last 300 ms, and the rest comes back at the next launch.

There is no "Save?" and no unsaved state to lose. A file nobody typed in is never written.

Held while it's open

While a file in iCloud Drive is open, Rune pauses iCloud's own syncing of it, saves in place, and uploads each version itself: 3 s after typing pauses, every 20 s while it goes on, and at once when you switch away, lock the screen, sleep the Mac or quit.

An upload fails rather than overwrite a newer version on the server. Rune fetches that version, merges, and uploads again.

Checks before you type

When Rune comes forward on a Mac, it asks iCloud for the newest version of what's open, so the Mac you switch to checks before you type.

What no Mac can know: a version another Mac hasn't uploaded yet, because it's asleep, offline or its lid closed mid-upload. Typing on the older copy then makes a merge, not a loss.

Merged, not overwritten

Edits from two Macs that don't overlap merge on their own, three-way, by line and then by word inside a line, as one step ⌘Z undoes. The same inputs give the same bytes on either Mac.

Conflicts in the text

Where both Macs changed the same lines, both versions go into the file between standard conflict markers, so nothing is lost even with Rune closed. Rune draws them as blocks: ⌘1, ⌘2 or ⌘3 keeps one side or both, and ⌥⌘R opens the merge view.

History for 30 days

Every version opened, merged, received from another Mac, restored or closed with, and the newest save of each 5 minutes. All of them for a day, hourly for a week, daily to 30 days. File › Revert To and the History window bring any back.

History and the journal stay on this Mac and never sync.

Receipts from your other Macs

Each Mac's Rune notes which version of each file it has loaded, so the strip can say ✓ SYNCED · ON AIR 10:42:31, or that Air has a newer one that isn't here yet.

Receipts travel through iCloud too, so they're as late as iCloud is.

iCloud's own copies

iCloud's conflict versions and duplicates such as scratch 2.md are found and brought into the same merge. An identical duplicate goes to the Trash.

Says what went wrong

A file deleted or moved to the Trash elsewhere gets a banner with Restore and Close. A file renamed or moved is followed. With iCloud Drive off, saves go to Rune's recovery folder and merge back when the file returns; with iCloud storage full, Rune keeps saving on this Mac and tries again.

A full disk is the one case where text lives only in memory. The strip says so in red, Rune tries again every 15 s, and it offers to empty the Trash when that would help.

02

Plain text in

Paste anything, get clean, unstyled text back, in Rune or in any other app.

Paste is always plain

⌘V in Rune inserts only the text: fonts, colors, links, images and attachments are dropped, and line endings become the document's. A clipboard with only HTML or RTF on it is turned into text.

Copy and Cut put plain text on the clipboard, never the syntax colors.

Paste Clean

⌥⇧⌘V also removes invisible characters (zero-width spaces, joiners, byte-order marks, soft hyphens, bidi controls), turns non-breaking and other unusual spaces into plain ones, and trims trailing whitespace.

Straightening smart quotes and dashes is a setting, off by default.

Clean Clipboard

⌃⌥⌘V, from any app, rewrites the clipboard in place as clean plain text, with no window. Then ⌘V pastes plain text wherever you are.

Append Clipboard to Scratch

Adds the cleaned clipboard to the end of scratch.md, after a blank line, without taking the focus. From the menu bar, or from a global shortcut you choose.

Copy Block

⇧⌘C copies the fenced code block at the caret without its fences, or the paragraph at the caret, with nothing selected. For terminal commands and email paragraphs.

From any app

Services › Clean Text puts a selection back as clean plain text; Services › Append to Rune Scratch adds it to scratch.md. In Shortcuts: Append to Scratch, Get Scratch and Clean Text.

A corrected edition of the An Old Hope color scheme: the purple taken out, and every text color at least 4.5:1 on the background. The same file installs in Sublime Text.

An Old Hope is © 2015 Jesse Leite, under the MIT license. Rune is dark only, always.

Import from Sublime Text

One click reads your color scheme, font, size, line padding, tab settings and word wrap from Sublime Text, and changes nothing there. Or import any .tmTheme or .sublime-color-scheme, with a report in plain words of what was imported, what isn't drawn, and colors under 4.5:1.

Sublime's keys

Sublime Text's default bindings for every command Rune has: ⌘L select line, ⌘J join, ⇧⌘D duplicate, ⌃⌘↑ ↓ move, ⌘/ comment, ⌘] ⌘[ indent, ⌃G go to line.

Multiple carets

⌘D adds the next occurrence, ⇧⌘L splits a selection into lines, ⌘-click adds a caret, ⌥-drag makes a column. Typing, deleting, the arrows, the clipboard and the line commands work at every caret.

⌘U takes back the carets' last change, as Sublime's soft undo does.

Find and replace

In a bar of Rune's own: regular expressions, match case, whole word, in selection. Replace All is one undo, and Find All puts a caret on every match.

Go to File

⌘P finds the scratch file, open files, recent files and the Rune folder: a name that starts with what you type comes first, then one that contains it, then one with its letters in order. ⇧⌘P opens every menu command with its shortcut; ⌘R lists a Markdown file's headings.

Minimap

Beside the scroller, as Sublime's: the text at a seventh of its size, each word a bar in its syntax color, conflict blocks in the muted red. Click or drag to scroll. View › Hide Minimap turns it off.

Files kept as they were

Saving keeps the encoding, line endings, final newline, permissions (a script stays executable), extended attributes, and the file itself, written in place. Line endings and indentation change from the View menu or the strip.

Big files too

Everything up to 5 MB. From 5 to 100 MB the strip says HIGHLIGHTING OFF · 42 MB and the file stays editable; above 100 MB Rune asks first.

04

A real Mac app

Show Scratch

⌥Space, from any app, brings the scratch window forward with the caret where you left it. Press it again and Rune steps back to the app you were in.

The keys can be changed in Settings › General, which warns when another app holds them.

One window of tabs

Files open as native tabs beside the scratch file, one buffer per file. ⌘O, Open Recent, Open With, a drag onto the Dock icon or the window. ⇧⌘T reopens a closed file, and the files open at a quit open again.

Untitled, still kept

⌘N and ⌘T open untitled tabs that are journaled like everything else and come back after a quit or a crash. Closing one keeps its text in History for 30 days, with no "Save?".

In the menu bar

A pixel ᚱ that stays still while all is well. Its line marches only when an upload has waited more than 3 s, and a red ✕ sits beside it while a conflict or a failed save needs you.

Its panel: the scratch file's state, Show Scratch, Clean Clipboard, Append Clipboard to Scratch and recent files. The Dock icon can be hidden while the ᚱ is in the menu bar.

Open with Rune

Settings › Files makes Rune the app for Markdown, plain text, JSON, CSS, JavaScript and shell scripts, a kind at a time. Turning one off gives it back to the app it had.

Notifications that matter

Only for a conflict, a save that failed, a file deleted, iCloud Drive turned off or iCloud storage full, and only while Rune isn't in front. Once while it lasts, taken back when it's over. Saves never notify.

VoiceOver and Reduce Motion

The strip reads as one summary ("scratch.md, synced at 10:42, line 14, column 3, Markdown"), glyphs are said as words, and conflicts and merges are announced. Under Reduce Motion nothing marches and the sync HUD fades in.

Quiet when idle

No timers while nothing happens: 0.00-0.05% CPU once settled. Rune never holds off sleep; it saves on the way to it.

Keeps itself current

Signed updates, checked once a day; Rune › Check for Updates… checks now.

The rune command, like Sublime's subl
$ rune notes.md:12 # opens it at line 12 $ export EDITOR="rune -w" # waits until the file is closed: git commit messages $ ls -la | rune # standard input as an untitled tab $ date | rune -a # appended to scratch.md, Rune left where it is $ rune --scratch # the scratch window
